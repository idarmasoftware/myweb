# Progress Tracking - Aplikasi Web

## Milestone Terakhir (03 Oktober 2026)
- **Modul Mata Kuliah:** Implementasi CRUD (Create, Read, Update, Delete) untuk tabel `mata_kuliah` telah selesai.
  - `mata-kuliah.php`: Menampilkan daftar mata kuliah (ditambahkan kolom Semester, SKS, dan tombol aksi).
  - `tambah-matkul.php`: Formulir penambahan data yang terhubung ke database.
  - `edit-matkul.php`: Formulir pengeditan data berdasarkan kode.
  - `hapus-matkul.php`: Skrip penghapusan data berdasarkan kode.
